# jizhang-buddy · 记账buddy

个人记账 Android App（自用）。本地存储、无账号、无联网。

## 功能

- 记账：支出/收入、7 大品类（可自定义）、5 个账户、自由备注 + 自动标签
- 校园卡截图导入：ML Kit 中文离线 OCR，自动过滤充值，疑似重复只标记不自动删
- 限额：日/周/月/年 + 各品类，80% 预警、超限每笔提醒（系统通知）
- 悬浮窗：无障碍服务监测拼多多/淘宝/京东/美团/支付宝，进入即显示、退出消失、可拖动、文案可自定义（支持 {已用} {剩余} {目标名} {还差} {N个月} 变量）
- 统计：日/周/月/学期/年，收支结余、分类、流水
- 报告：本地规则引擎生成每日/每周/每月报告，含消费健康度评分、表扬与批评
- 导出：一键导出 JSON/CSV/MD（含每笔备注原文与自动标签），可分享给 AI 分析
- 提醒：每日总结 22:30、周报周日 21:00、理财提醒周六 22:00

## 构建

推送 main 分支后 GitHub Actions 自动编译 debug APK 并发布到 Release。

技术栈：Kotlin 1.9.24 · AGP 8.5.2 · Jetpack Compose (BOM 2024.06) · 原生 SQLite · ML Kit
